Deviations from the specification and run settings
- Replications: the specification asks for 20 per cell, reduced to 10 if runtime is too long.
  A first attempt with 10 replications was stopped after one replication, because a concurrent
  CPU job made each replication about seven times slower. The full run used 8 replications per
  cell (128 in total) with R = 50, which fit the 90-minute target. Replication 0 of the first
  cell was kept from the interrupted attempt (same seeds, same code path).
- Population size: N_pop = 100,000 as specified for this exercise. DESIGN.md Section 4 states
  200,000; the exercise specification takes precedence here.
- Simulation replicates: R = 50 for C2, C3, C4 (the exercise specification). DESIGN.md states 100.
- The truth and the oracle use the same test population in each replication, so their
  difference is not affected by population sampling noise.
- The C3 quantile forest is fitted once per replication and shared across the four point models,
  because it does not depend on the point model. Its seed is fixed per cell and replication.

Notes
- The true poverty line is recomputed from each replication's population median.
- OOF R2 of lgbm at n=2000 is low (about 0.02 at target R2 = 0.2) because the specified
  settings (500 trees, learning rate 0.05, 31 leaves, min_child_samples 50, no early stopping)
  overfit a 1,600-row fold. Results for lgbm at n=2000 should be read with that in mind.
